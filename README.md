# 4 en 1
Abre hasta 4 apps a la vez, una en cada esquina de la pantalla.

## Compilar
Sube el proyecto a GitHub (rama `main`). En la pestaña **Actions** se ejecuta *Build APK*;
descarga `CuatroEnUno-debug` desde **Artifacts** y instala `app-debug.apk`.

## Requisito en el teléfono
Android 10+ con **Ventanas de forma libre** y **Forzar actividades redimensionables**
activadas en Opciones de desarrollador (reinicia después).
